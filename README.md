# STAT420-626-F26-Project

## Running in Google Colab

1. Launch [Google Colab](https://colab.research.google.com/) and open [`STAT626_100_Patients_2D_Colab.ipynb`](STAT626_100_Patients_2D_Colab.ipynb).
2. Upload the project files from this repository into your Colab session folder.
3. Enable GPU acceleration under **Runtime > Change runtime type**:
   - **Preferred:** A100 GPU
   - **Alternative:** L4 GPU
4. Follow [`START_HERE.md`](START_HERE.md) for full documentation and step-by-step execution instructions.
